# 災防居士

台灣災防感測技術的法規與認證筆記，例如〈[熱像儀是火警探測器嗎？](./01-熱像儀是火警探測器嗎.md)〉。

## 專案結構

- `災防居士-site/site/` — Astro 網站原始碼（筆記以 content collection 管理）
- `*.md` — 草稿筆記

## 本機開發

```bash
cd 災防居士-site/site
npm install
npm run dev      # http://localhost:4321
```

更多細節（新增筆記、部署方式）見 [`災防居士-site/site/README.md`](./災防居士-site/site/README.md)。
